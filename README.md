# IEM Careers

Openings, resources and events for the MSc IEM cohort at Imperial.

- `index.html`: the hub
- `data/`: openings, resources and events, refreshed every morning
- `backend.js` + `config.js`: connection to the Supabase database that stores names, ticks and RSVPs
- `supabase.sql`: database tables and privacy rules

Visitors are asked for their name once per device. Only organisers (emails listed in the `admins` table) can see who's going to events.
